# Pizza Sales Analysis | SQL Server & Power BI

## Project Overview
This project analyzes pizza sales data using SQL Server and Power BI to understand sales performance, customer ordering patterns, and product performance.

The analysis helps answer business questions about revenue, order volume, popular pizza products, and sales trends.

## Business Objectives
- Evaluate overall sales performance.
- Identify the best- and worst-selling pizzas.
- Analyze orders by day and month.
- Compare revenue and quantity sold by pizza category and size.
- Understand which products contribute most to revenue.

## Tools Used
- SQL Server — data analysis and querying
- Power BI Desktop — dashboard development
- Microsoft Excel / CSV — source data

## Key Performance Indicators
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## SQL Analysis
The SQL queries cover:
- Overall sales KPIs
- Daily and monthly order trends
- Revenue contribution by pizza category and size
- Pizza category quantity analysis
- Top and bottom 5 pizzas by revenue, quantity, and orders

## Power BI Dashboard
The dashboard presents sales KPIs, trends, category and size comparisons, and product rankings.

## Notes
Revenue is calculated from the `total_price` column. This dataset does not include ingredient costs or operating expenses, so the project analyzes revenue rather than profit.
